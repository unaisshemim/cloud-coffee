---
title: "Using the API"
description: "Authenticate cloudcoffee API requests with OAuth bearer tokens and integrate resume data into scripts, apps, or automations."
---

cloudcoffee exposes an OpenAPI-compatible HTTP API under `/api/openapi`. Machine clients authenticate with OAuth 2 access tokens.

<Steps>
  <Step title="Open the API reference">
    Review the [API Reference](https://docs.rxresu.me/api-reference) for available endpoints and request schemas.
  </Step>

  <Step title="Authorize an OAuth client">
    Use an OAuth-capable client to complete authorization against your cloudcoffee instance. The authorization server publishes standard discovery metadata and issues bearer access tokens for authenticated users.

    <Info>
      MCP clients normally perform this flow automatically. Custom integrations must implement OAuth authorization-code flow with PKCE and securely refresh tokens when required.
    </Info>
  </Step>

  <Step title="Send the bearer token">
    Include the access token in the standard <Badge>Authorization</Badge> header.

    ```bash
    curl "https://rxresu.me/api/openapi/resumes" \
      -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
    ```

    <Info>
      If you're self-hosting, replace <code>https://rxresu.me</code> with your instance URL.
    </Info>
  </Step>
</Steps>

<Warning>
  Treat access and refresh tokens as secrets. Never commit them to source control or expose them in browser-delivered code.
</Warning>
